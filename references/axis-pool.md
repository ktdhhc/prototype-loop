# 参考轴池

> 拆层时逐条问“本界面有这个轴吗”。这是从一个管理台页面提取的**静态示例，不是通用层序或轴全集**。当前项目的新轴记在该项目账本中，不更新本文件。

**独立性判定法**：一个轴成立，当且仅当它能"在保持其他轴不变的情况下独立变化"。能 → 独立轴；不能 → 并入它依附的轴。判据例："信息密度"能独立于"信息类型"变化（同一份字段清单可配三种密度）→ 独立轴；"字段取舍"不能脱离"信息类型"独立变化 → 并入。

## 池

| 轴 | 唯一决策点 | 明确不决定 | 独立性测试要点 |
| --- | --- | --- | --- |
| 骨架布局 | 页面切成几块、各块在哪 | 每块放哪些字段、动作怎么排 | 改骨架必然牵动几乎所有后续层 → 影响半径最大，排最前 |
| 信息类型 | 承载哪些事实、分几类、谁承担主身份；术语 | 占多大空间、默认藏不藏 | 同一组事实可换多种密度与折叠方案 → 独立于密度与折叠 |
| 信息密度 | 每个单位承载多少（一行放几个、谁大谁小谁靠上） | 藏什么、展开后是什么 | 同一份字段清单可配多种密度 → 独立于信息类型（这是最容易漏的轴：字段定了不等于密度定了） |
| 折叠逻辑 | 默认可见与折叠的边界、展开容器 | 密度档位、动作位置 | 同一密度下可换折叠方案（行内 / 浮层 / 抽屉）→ 独立 |
| 运行 / 主流程流转 | 发起点、过程发生地、结果与证据落点、跨页缝线 | 面板视觉形态、动效 | 只存在于有"过程"的界面（操作台、任务页）；纯展示页无此轴 |
| 动作组织 | 动作清单、主次、位置（常驻 / 菜单 / 批量）、触发方式 | 按钮视觉形态 | 同一批动作可平铺也可进溢出菜单 → 独立于组件样式 |
| 组件样式 | 本页新原子的视觉形态（序号、批次条、标签、行、按钮族） | 要不要这些元素（前序层已定） | 有设计系统时本轴 = **归一**（对齐既有 token 与组件推荐值），不是发明 |
| 状态与边界 | 空 / 加载 / 错误 / 权限 / 阻断 / 超长各自的可见表达 | 正常态长什么样 | 改状态呈现几乎不影响其他层 → 影响半径最小，排最后 |

对当前页面独有的维度，例如“权限可见性”，在本项目账本中写明决策点、独立性与归属层；其他项目继续从自身事实出发重新拆层。
