# 过程账本模板

> 这是 prototype-loop 在当前目标项目内复制使用的账本骨架：界面访谈时建立，拆层时补齐初版与测试，贯穿逐层原型与收口。项目之间不回填设计结论。
> 位置约定：`.scratch/prototype/<页面名>/LAYER-DECISIONS.md`。性质：**非铁律**——只作为最终原型合并与后续接线的交互参考，随时可能变化；不是 Spec、不是 ADR，不进入正式验收基线。

## 使用要点

1. **访谈时建立**：先记录界面简述；拆层时就将分层表初版与变体证明写进去，不到收口才补写。
2. **逐题记录决定性问答**：每层必须核对，答案及其对做法的影响写入当前层；零提问记录核对项与答案来源，不由原型初选推断完成。
3. **收层留证据**：分别记初选、结论确认与推进授权；按 [层循环](prototype-loop.md) 记录产物整理和验证，未过闸门保持待收层。初选后仍有未定决策则保持进行中。
4. **`ΔDESIGN` 及时标**：用户确认本层结论时，凡涉及视觉依据的变化当场标记，收口 6.1 才扫得出来。
5. **跨层待办是唯一的中转站**：不属于当前层的用户输入一律先入表，到所属层再处理——处理路径只有两条：账本里，或所属层的执行里。
